# Werkstudent Job & Application Tracker

Ein schlanker Fullstack-Tracker für deine Bewerbungsoffensive (Werkstudent IT & Non-IT in Berlin).

## Projektstruktur
- `database.py`: SQLAlchemy-Engine, Session-Management und Datenmodelle
- `schemas.py`: Pydantic-Schemas für Validierung und API
- `main.py`: FastAPI-App, Endpunkte und Dashboard-Routen
- `templates/`: HTML-Templates (Jinja2) für das Dashboard
- `static/`: Statische Assets (CSS, JS)
